## 文档维护规则

1. **变更留痕**：文档改版升版本号，重大变更写进 CHANGELOG
2. **冲突裁决**：PRD（为什么）→ Spec（精确到什么程度）→ TRD（怎么做），有冲突以 Spec 为准
3. **评审记录不删改**：只追加，决议错了也留着——那是决策的痕迹
4. **复盘文档**（模板 06）在上线运行一周后创建
