## Bug 清单

### BUG-1 长文摘要超时（用户实测反馈，已修复）

- **复现**：保存 `https://bookfere.com/novice/comment-page-3`（正文 16071 字），摘要阶段 30 秒超时失败
- **根因**：两层——① deepseek-r1:7b 是推理模型，生成前输出大量思考 token，长输入放大该问题；② Spec S2.3 的 30s 超时是按 qwen2.5:3b（非推理、更快）定的
- **修复**（commit `fix: 测试bug#1`）：
  - 摘要输入 8000 → 3000 字（首 3000 字足以概括）
  - `num_predict: 500` 上限防思考失控
  - `SUMMARY_TIMEOUT_MS` 环境变量可覆盖 30s 默认值（r1 跑 180s）；**Spec 值不变**，qwen 上线后回归 30s
  - 超时提示从裸英文改为可读中文
- **顺带修复**：HTML 实体未解码（标题显示 `&#8211;` → 现在 `–`）
- **回归验证**：同文章重试 → `done`，摘要准确，T+30s 内完成
- **遗留**：qwen2.5:3b 下载完成后切回，复测 30s 时限是否满足 Spec S2.3
