# ADR-001：摘要生成采用串行 worker 而非消息队列

- 状态：已接受（Accepted）
- 日期：2026-10-03
- 决策人：研发

## 背景

摘要生成依赖本地 Ollama，是慢操作（数秒到数分钟），不能在 HTTP 请求内同步完成。需要一种异步执行机制。

## 决策

采用**进程内串行 worker**：SQLite 的 `pending` 任务表即队列，worker 循环取一条执行，同一时刻只有一篇在生成。不引入 Redis / RabbitMQ / BullMQ。

## 理由

1. 本地单实例 Ollama 并发能力 ≈1，多 worker 排队等待没有收益
2. 免维护额外中间件，MVP 部署保持 `docker-compose up` 一条命令
3. 重启丢任务的问题用「启动时扫描 pending/fetched 重入队」弥补，代价极小

## 后果

- 正面：部署简单、调试直观、无新依赖
- 负面：单机吞吐上限 = 模型吞吐；多实例部署需改造为分布式队列
- 触发重评条件：需要多实例水平扩展，或接入云端推理 API 时
