# ADR-002：Ollama 留在宿主机，不进容器

- 状态：已接受（Accepted）
- 日期：2026-10-03
- 决策人：研发

## 背景

摘要模型通过 Ollama 提供。容器化方案有两种：把 Ollama 打进 Docker，或让容器内的应用访问宿主机已有的 Ollama 服务。

## 决策

Ollama **不进容器**。应用容器通过 `host.docker.internal:11434` 访问宿主机 Ollama。

## 理由

1. 宿主机已装好 Ollama 且模型已就位，复用省去约 2 GB 镜像
2. 模型权重放宿主机，容器重建不触发重新下载
3. GPU 直通在宿主机进程上更简单，嵌套容器化会增加一层复杂度

## 后果

- 正面：镜像小、启动快、模型管理独立于应用生命周期
- 负面：部署依赖宿主机环境（生产上云时若用纯容器平台需要调整）
- 触发重评条件：迁移到云平台部署（届时评估 Ollama 官方镜像 + 挂载卷方案）
